義恒（よしつね）SNS投稿ツール

このツールは、義恒（よしつねの秘密基地）が自社のSNSアカウント（Instagram・Facebook・X・YouTube・TikTok）に、自社で制作した4コマ漫画「福合わせたぬき猫」を投稿するためだけに使う、社内用のツールです。一般の方が利用するサービスではありません。

プライバシーポリシー

  • このツールが扱うのは、義恒が管理する自社アカウントの情報と、投稿する画像・動画・文章だけです。
  • 第三者の個人情報を集めたり、保存したり、販売・共有したりすることはありません。
  • 各SNSとつなぐための合言葉（アクセストークン）は、暗号化して安全な場所に保管し、投稿以外の目的には使いません。
  • 連携をやめたいときは、各SNSの設定画面からいつでも解除でき、解除と同時にこのツールからは使えなくなります。
  • このツールは Cookie を使いません。

YouTube API サービスの利用について

  • このツールは YouTube API サービスを使って、義恒が制作・承認した動画を義恒自身の YouTube チャンネルにアップロードします。
  • 使う権限は「動画のアップロード」（youtube.upload）だけです。視聴履歴・登録チャンネル・コメント・ほかの人のデータなどは読み取りません。
  • YouTube から受け取る情報は、アップロードした動画のID（投稿のリンクを記録するため）だけです。それ以外の情報は保存しません。
  • Google による情報の取り扱いは、Google プライバシーポリシーをご覧ください。
  • このツールへの YouTube の許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。取り消すと、保管している合言葉（リフレッシュトークン）は使えなくなり、7日以内に削除します。
  • 保管している情報の削除を希望される場合は、下記のお問い合わせ先までご連絡ください。7日以内に削除します。

利用規約

  • このツールを使えるのは義恒だけです。
  • 投稿する内容は義恒が確認・承認したものに限り、各SNSの利用規約とガイドラインに従います。
  • AIで作った画像を使う投稿には、各SNSのルールに従ってAI生成である旨を表示します。
  • このツールの YouTube 機能を使うことで、YouTube 利用規約に同意したものとみなします。
